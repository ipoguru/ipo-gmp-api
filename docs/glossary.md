# Glossary

Indian primary-market terms, for developers integrating from outside the market.

| Term | Meaning |
|---|---|
| GMP | Grey Market Premium: the unofficial price at which an IPO application or share trades before listing. Indicative sentiment, not a regulated quote. |
| Kostak | A flat price paid for an IPO application, payable whether or not it gets an allotment. |
| Subject to Sauda | A price paid for an application only if it gets an allotment. Usually higher than kostak. |
| Mainboard vs SME | Mainboard issues list on the main NSE/BSE platform; SME issues list on NSE Emerge or BSE SME, with smaller sizes and larger lots. |
| Pre-RHP | A mainboard issue already quoted in the grey market before its Red Herring Prospectus dates are announced. The API returns `stage: "pre_rhp"` and `dates_tba: true`. |
| QIB | Qualified Institutional Buyers: banks, insurers, mutual funds and FIIs. |
| NII / HNI | Non-Institutional Investors, applying above ₹2 lakh. Split into sNII (₹2–10 lakh) and bNII (above ₹10 lakh). |
| RII / Retail | Retail Individual Investors, capped at ₹2 lakh per application. |
| Anchor investor | An institution allotted shares one working day before the issue opens, at a fixed price, with a lock-in. |
| Lot size | The minimum number of shares per application. Applications are whole multiples of it. |
| Basis of allotment (BoA) | The registrar's document showing how shares were allotted across categories after the issue closes. |
| OFS | Offer For Sale: existing shareholders selling through the exchange bidding window, in separate retail and non-retail tranches. |
| Green shoe | An over-allotment option letting the seller place extra shares if demand exceeds the base size. |
| Unlisted / pre-IPO shares | Shares of companies not yet listed, traded off-exchange through dealers. Prices are indicative dealer quotes. |
